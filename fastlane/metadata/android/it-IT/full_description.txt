Semplice app open-source per Android TV per riprodurre musica dai tuoi server Subsonic o Navidrome o dallo spazio locale.

Chora ha un'interfaccia semplice e moderna pensata per la TV, realizzata con Material 3, con sfondi del player colorati in base alla copertina e testi sincronizzati.

Importante: Chora non fornisce musica. È solo un front-end per server Subsonic e/o spazio locale, quindi l'utente deve fornire i file musicali.
