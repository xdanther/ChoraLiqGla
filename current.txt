# ChoraLiqGla — project notes

## Goal

An Android / Android TV client for Navidrome and Subsonic servers, with a mobile
app and a separate 10-foot TV interface. The TV interface is being rebuilt to feel
like Apple Music on Apple TV: black artwork-led canvas, colour taken from the
cover, Apple TV type sizes and margins, a sidebar reached from the remote's Menu
key, an Apple-style now-playing bar, synced lyrics, and an info card. Everything
new must be an opt-in setting so no existing behaviour breaks.

## Status

- The app builds as a release APK in CI; signing is unified on `signing/chora-release.jks`.
- TV player has been rebuilt around the Apple TV reference: 28% cover, 24sp title,
  15sp artist, 40dp side and 30dp vertical margins, 38dp glass circle buttons,
  full-width scrubber, Info pill, queue/more/lyrics actions, info card with two
  rounded actions, share-as-QR, palette-blob wash, lyrics with blurred backdrop.
- Last completed: bar closes only on Down/Back; Back closes the info card; Up from
  every bar button reaches the scrubber; untimed lyrics spread across the track;
  10 s seek increments so the remote's FF/REW work; QR share flow.
- Verification: none of the player work has been run on a device or emulator.
  Local Gradle can no longer resolve the Android plugin offline, so every change
  since `ac42161` is only proven by CI (or by the one error CI reported at `b6a1ae7`).
- Known gap: `onGoToArtist` is accepted by the player but `NowPlaying` passes the
  default no-op, so Go to Artist appears without navigating.

## Decisions

- New TV behaviour ships as settings, never as a replacement for existing options.
- Apple lyric pane is opt-in (`appleTvLyrics`); the shared `LyricsView` stays default.
- Sidebar is settings-driven (`bottomNavItemsFlow`), opened by Menu/Back on Home,
  never by the player.
- Background wash: drifting palette blobs (commit `1366514`). Rejected: blurred
  cover copies (looks like smeared artwork) and an AGSL domain-warped shader.
- Info card replaces the bar in place, and Back restores the bar.
- Bar surfaces are translucent glass of the player's ink with a hairline outline.
- Shares use the server's `createShare` with an expiry, encoded by the in-repo QR
  encoder (verified decodable with OpenCV).
- Type and spacing follow Apple's 1920x1080 point grid, so 1 pt = 0.5 dp here.
- Never run a local Gradle build; CI builds. Only `compileReleaseKotlin --offline`
  was ever allowed locally, and that no longer resolves.
